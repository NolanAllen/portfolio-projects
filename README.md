# Portfolio Projects
A diverse collection of eight C++ projects showcasing various skills including dynamic programming, encryption, game system programming, and file parsing with regex. Full details can be found in Project_Portfolio.pdf in this repository. A brief overview is provided below.

## ps0: Hello SFML
A simple introductory project to using Simple and Fast Multimedia Library (SFML) for displaying graphics. Run with `.\sfml-app`.

## ps1a and ps1b: PhotoMagic
An image encryption/decryption program using a Fibonacci linear feedback shift register (LFSR). Run with `.\PhotoMagic [input file] [output file] [password or 16-bit seed]`.

## ps3a and ps3b: StringSound
A program to synthesize the plucking sound of a guitar string by procedurally building the sound file. Run with `.\KSGuitarSim (instrument)`, with the optional `instrument` argument currently supporting `Guitar` and `SpringSynth`.

## ps4a and ps4b: Sokoban
The classic warehouse management puzzle game with some added elements like pressure plates and temporary walls. Run with `.\Sokoban (level file)`.

## ps5: DNA Alignment
A dynamic programming approach to determining the best alignment for two DNA sequences. Run with `.\EDistance < [input file] > [output file]`.

<img width="511" height="302" alt="ps5" src="https://github.com/user-attachments/assets/7e1b6223-6a6d-4d0d-a4db-28c36fc8c3d5" />

## ps6: RandWriter
A program to build a probabilistic model of written language from given input text and generate text based on a prompt. The two programs, one based on characters and one based on words, can be run with `.\TextWriter [number of characters to generate] [substring length] < [input file]` and `.\WordWriter [number of words to generate] [substring length, in words] < [input file]`.

## ps7: Kronos Log Parsing
A program to use regular expressions to parse output logs from a Kronos InTouch time clock and assemble an output file containing times and durations of boots and related services. Run with `.\ps7 [log file]`.
